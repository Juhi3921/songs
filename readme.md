# NEON NIGHT 🎵

A 30-second interactive music project made with **HTML, CSS, JavaScript, and Strudel**.

Neon Night is a small browser-based music experiment where users can play a generated song, change individual music parts, switch moods, play piano notes, and view the live Strudel code behind the music.

## ✨ Features

### 🎵 30-Second Music Player

The project plays a 30-second song created using Strudel.

It includes:

- Play
- Stop
- 30-second timer
- Progress bar
- Animated visualizer

### 🎚️ Part Mixer

The song is divided into four parts:

| Part | Description |
|------|-------------|
| Drums | Kick, snare and hi-hat rhythm |
| Bass | Low synth groove |
| Lead | Main melody |
| Variation | Clap and open hi-hat changes |

Each part has its own volume control.

The mixer can also be changed while the song is playing.

### 🎭 Mood Selector

The music can be changed using different moods:

- HAPPY
- DARK
- CHILL
- ENERGETIC
- MYSTERIOUS

Each mood uses different drum, bass, lead and variation patterns.

### Mini Piano

A small piano keyboard is included so users can click notes and hear them.
